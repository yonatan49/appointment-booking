# Appointment Booking for Beauty Salons

A full-stack appointment booking system for beauty and nail salons. Customers can book a service in a guided flow, while salon staff manage appointments from an admin dashboard.

## Features

- Browse salon services with prices and durations
- Four-step booking flow: service, artist, date & time, and customer details
- Artist eligibility based on the selected service, with a random-artist option
- Available time-slot selection and booking form validation
- Booking confirmation with appointment summary
- Secure admin login with invalid-credential feedback
- Weekly admin calendar for viewing appointments
- Appointment detail view with editable booking status

## Tech Stack

| --- | --- |
